Title: Show HN: Sighting – a lost and found board for pets with no accounts

Sighting is a lost and found board for pets. The one design rule is that a person who just lost a dog will not make an account, so there are none. Posting returns a private edit-token link, and every edit goes through a Postgres function that checks the token on the server, so table writes are denied outright. Web plus native apps from one Kotlin Multiplatform codebase. https://sighting.jaybulb.com
